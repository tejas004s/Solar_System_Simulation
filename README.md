## 🌠 Overview

This project visualizes the solar system using WebGL and Three.js, offering an interactive experience where users can explore planetary motion, scale, and aesthetics.  
Hosted live on Render: [solar-system-simulator-latest.onrender.com](https://solar-system-simulator-latest.onrender.com/)

---

## ✨ Features

- 🪐 Real-time orbital simulation
- 🎮 Interactive camera and controls
- 🌈 Scaled visuals with lighting and textures
- 📱 Responsive design for desktop and mobile
- ⚙️ Modular codebase for easy extension

---

## 🚀 Getting Started

To run locally:

```bash
git clone https://github.com/tejas004s/Solar_System_Simulation.git
cd Solar_System_Simulation
npm install
npm start
```

Then open `http://localhost:3000` in your browser.
