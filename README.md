This  project is an engaging and educational web-based solar system simulator designed to help users visualize and understand the scale of the universe. 
It leverages modern web technologies, including HTML, CSS, JavaScript, and Three.js, to create an interactive 3D environment where celestial bodies like the Sun, planets, and their orbits are rendered. 
The application is containerized using Docker with an Nginx server to serve the static assets efficiently, making it portable and easy to deploy.The simulator features a rotating Sun and planets, each positioned at scaled distances with corresponding orbital paths, and includes a user interface with mouse and keyboard controls for navigation (e.g., W/A/S/D for movement, mouse for rotation).
Planets are enhanced with textures and labels, while the Sun is designed with a glowing effect to mimic its real-world appearance. The project is structured in chapters, starting with setting up a basic 3D scene and progressively adding complexity, such as planet details and interactive elements.
Currently, it’s built as a single-page application hosted within a Docker container, with plans to expand features like additional celestial bodies (e.g., moons) or deployment to cloud platforms for broader access. 
The goal is to provide an immersive learning tool that showcases astronomical scales and dynamics in an accessible format.
